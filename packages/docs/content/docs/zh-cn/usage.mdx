# 用量与配额

用量页面显示你已使用的每个提供商套餐的额度，让你能看到自己距离限额还有多远。在 **Settings → Usage** 中打开它。

## 你能看到什么

对于每个已连接的提供商，OpenChamber 会显示：

- 当前周期内你已使用的量，以进度条形式展示
- 按模型的细分
- 一个速率指示器，让你判断自己是否会用尽额度

你可以选择哪些提供商出现在此处，相同的摘要也可以从应用标题栏的下拉菜单中查看。

## 支持的提供商

用量功能适用于公布订阅配额的引擎 Claude 和 Codex。

OpenChamber 会读取 Claude Code 或 Codex CLI 已保存在运行 OpenChamber 的机器上的登录信息，所以在用量页面上无需填写任何内容。请用 `claude auth login` 或 `codex login` 登录。如果某个提供商没有显示数据，说明该机器上对应的 CLI 尚未登录。
