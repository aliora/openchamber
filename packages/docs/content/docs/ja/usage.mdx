# 使用量とクォータ

Usage ページでは、各プロバイダープランをどれだけ使ったかを確認でき、上限にどれだけ近いかが分かります。**Settings → Usage** から開きます。

## 表示されるもの

接続済みプロバイダーごとに、OpenChamber は次を表示します。

- 現在のウィンドウでどれだけ使ったかをバーで表示
- モデル別の内訳
- 使い切りそうなペースか分かる pace インジケーター

表示するプロバイダーは選べます。同じサマリーはアプリヘッダーのドロップダウンからも確認できます。

## 対応プロバイダー

Usage は、サブスクリプションのクォータを公開しているエンジン、Claude と Codex で動作します。

OpenChamber は、Claude Code または Codex CLI が OpenChamber を実行しているマシンにすでに保存しているサインイン情報を読み取ります。そのため、Usage ページで入力するものはありません。`claude auth login` または `codex login` でサインインしてください。プロバイダーにデータが表示されない場合、そのマシンで該当する CLI がサインインしていません。
