# 사용량 및 할당량

Usage 페이지는 각 공급자 요금제를 얼마나 사용했는지 보여주므로 한도에 얼마나 가까운지 확인할 수 있습니다. **Settings → Usage**에서 엽니다.

## 표시되는 내용

연결된 각 공급자에 대해 OpenChamber는 다음을 표시합니다.

- 현재 기간 동안 사용한 양을 막대로 표시
- 모델별 분석
- 한도에 도달할 추세인지 알 수 있는 사용 속도 지표

어떤 공급자를 표시할지 선택할 수 있으며, 동일한 요약은 앱 헤더의 드롭다운에서도 확인할 수 있습니다.

## 지원되는 공급자

Usage는 구독 할당량을 공개하는 엔진인 Claude와 Codex에서 작동합니다.

OpenChamber는 Claude Code 또는 Codex CLI가 OpenChamber를 실행하는 컴퓨터에 이미 저장해 둔 로그인 정보를 읽습니다. 그래서 Usage 페이지에서 입력할 것은 없습니다. `claude auth login` 또는 `codex login`으로 로그인하세요. 공급자에 데이터가 표시되지 않는다면 해당 컴퓨터에서 그 CLI에 로그인되어 있지 않은 것입니다.
